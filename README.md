# Elfar Tasks 🐭

تطبيق مهام للاب: فولدرات ← فولدرات فرعية ← تاسكات ← مهام فرعية، مع مصفوفة أولويات، متابعة الأشخاص، تذكيرات، وويدجت على سطح المكتب.

Credit: **Mamdouh Elfar** — الاقتراحات من داخل التطبيق: الإعدادات ← عن التطبيق ← ابعت اقتراح.

## التشغيل (للتطوير)

```bash
npm install
npm start
```

## أهم المميزات

- **العروض**: النهارده، المصفوفة (مهم/مستعجل)، Pending، متأخرة، معلّق عند، مقفولة، التقويم، التقرير.
- **التاسك**: Start / Due / Closure (من غير Closure = Pending)، تكرار (يومي/أسبوعي/شهري/سنوي)، تذكير بإشعار ويندوز، ملفات ولينكات، ملاحظات، سجل متابعة بالوقت والمسؤول، ومسار يوضح التاسك قعدت عند مين قد إيه.
- **الويدجت**: يا إما دايماً فوق كل البرامج، يا إما يستخبى على حافة الشاشة ويطلع بالـ hover.
- **ملخص الصبح** وتنبيه للتاسكات المتعطلة عند ناس.
- **التقرير**: نسخ كنص أو تصدير Excel (CSV).
- **تراجع (Undo)** بعد القفل أو الحذف.

## الاختصارات

| الاختصار | الوظيفة |
|---|---|
| Ctrl+N | تاسك جديد |
| Ctrl+Alt+Space (أو Ctrl+Shift+Space لو الأول مستخدم) | إضافة سريعة من أي برنامج |
| Ctrl+K | بحث في كل حاجة |
| ↑ ↓ | تنقل بين التاسكات |
| Space | قفل / فتح التاسك |
| 1 – 4 | التصنيف في المصفوفة |
| S | تمييز ★ |
| Delete | حذف (مع تراجع) |
| Ctrl + / Ctrl - / Ctrl 0 | حجم الخط |
| Esc | قفل النافذة / التاسك المفتوحة |

## البيانات

- محفوظة في `%APPDATA%\Elfar Tasks\data.json`، ومعاها نسخة احتياطية تلقائية كل يوم لآخر 30 يوم (`backups`).
- تقدر تنقل مكان الحفظ لفولدر OneDrive من الإعدادات عشان نفس البيانات تبقى على أكتر من جهاز.
